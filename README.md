# TPI-Final-Minotti-Santiago

## Integrantes: Minotti Santiago
## Carrera: Tecnicatura Universitaria en Programación a Distancia

### Descripción: Este proyecto implementa un módulo de software automatizado para la evaluación de riesgo crediticio en tiempo real dentro de Mercado Libre. El sistema se encarga de analizar la salud financiera del comprador o vendedor para aprobar o rechazar la patición, interactuando directamente con el motor transaccional de Mercado Pago para los desembolsos inmediatos.

### Declaración de uso de IA: Se ha utilizado un asistente de Inteligencia Artificial como herramienta de apoyo para la estructuración conceptual del modelado de procesos BPMN 2.0.
